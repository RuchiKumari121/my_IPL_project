# IPL Data Analysis

## Project Overview

This project analyzes IPL match data using Python to explore match results, player performances, venues, toss decisions, and winning patterns.

The project focuses on data cleaning, exploratory data analysis (EDA), and data visualization using Python libraries.

## Objectives

The main objectives of this project are:

* Analyze IPL match data and identify important patterns.
* Find the highest individual scores.
* Identify the best bowling figures.
* Find players with the most Player of the Match awards.
* Identify venues that hosted the most matches.
* Analyze winning margins by runs and wickets.
* Compare toss winners with match winners.
* Analyze toss decisions and match outcomes.
* Create meaningful visualizations from the data.

## Dataset

The dataset contains IPL match-level information such as:

* Match ID
* Date
* Venue
* Teams
* Toss winner and toss decision
* First innings score and wickets
* Second innings score and wickets
* Match winner
* Winning method and margin
* Player of the Match
* Top scorer and highest score
* Best bowling performance and bowling figure

## Data Cleaning

The dataset was cleaned and prepared before analysis.

Some of the tasks included:

* Checking the shape and structure of the dataset.
* Checking data types.
* Checking for duplicate records.
* Converting the date column into a datetime format.
* Handling formatting inconsistencies in the date column.
* Extracting useful information from bowling figures.

## Analysis Performed

The project answers questions such as:

1. Which player had the highest individual score?
2. Which players received the most Player of the Match awards?
3. Which venues hosted the most matches?
4. Which team won by the highest margin of runs?
5. Which teams won matches by runs and wickets?
6. What were the best bowling figures?
7. How often did the toss winner also win the match?
8. What were the most common toss decisions?

* First innings score vs second innings score — Scatter Plot
